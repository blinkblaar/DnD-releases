# DnD Host – Installer

Hier liegen die Windows-Installer für **DnD Host**, die Desktop-App für den Host des D&D-Spiels mit KI-Spielleiter.

**Download:** unter [Releases](https://github.com/blinkblaar/DnD-releases/releases/latest) die neueste `DnD-Host-Setup-x.y.z.exe` herunterladen und ausführen.

- Den Installer braucht nur, wer das Spiel hostet. Mitspieler kommen per Link im Browser dazu.
- Die App sucht beim Start selbst nach neuen Versionen und bietet das Update in einem Fenster an. Spielstände und Einstellungen bleiben dabei erhalten.
- Der Installer ist nicht signiert. Beim ersten Start zeigt Windows „Der Computer wurde geschützt“: über „Weitere Informationen“ und „Trotzdem ausführen“ geht es weiter.

Die Installer werden automatisch gebaut. Dieses Repo enthält keinen Quellcode.
